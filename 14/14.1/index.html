Responsive Display Utilities

Use d-none, d-md-block, and d-lg-flex to hide and show layout sections based on screen size.

Resize the browser to see the responsive display utilities change which sections are visible.

Hidden Section

This block uses d-none, so it stays hidden on every screen size.

Tablet and Desktop Section

This block is hidden on small screens, then appears from medium screens because of d-none d-md-block.

Large Screen Flex Section

This block appears only on large screens and becomes a flex layout with d-none d-lg-flex.

Class Summary

  • d-none hides an element.
  • d-md-block shows it as a block from medium screens.
  • d-lg-flex shows it as flex from large screens.

Current Exercise Goal

Build sections that appear or disappear at different Bootstrap breakpoints using only responsive display classes.
