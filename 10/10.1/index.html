Exercise 10.1

Responsive Navbar with Logo, Links, and Search

Resize the page to see the navigation collapse into a mobile menu powered by the local Bootstrap bundle.

Logo

The brand area uses navbar-brand with a simple logo mark.

Links

Navigation links use navbar-nav, nav-item, and nav-link.

Search

The search form uses Bootstrap form and button classes inside the navbar.

Class summary

Class Purpose
navbar navbar-expand-lg Creates a responsive navbar that expands from large screens.
navbar-brand Styles the logo and brand name.
collapse navbar-collapse Wraps collapsible links and search form for mobile screens.
d-flex Lays out the search input and button in a row.
