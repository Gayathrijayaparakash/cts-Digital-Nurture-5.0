Media Object Layout

Align an image to the left of content using Bootstrap flex utilities.

Bootstrap 5 media object pattern

The older media component was removed in Bootstrap 5, so this layout uses d-flex, flex-column, flex-md-row, and align-items-start.

Priya Mehta

Online

This is a media object: the image stays to the left while the text content sits to the right on medium screens and larger.

d-flex flex-md-row align-items-start

Responsive Article Preview

Media object layouts are useful for comments, profile rows, article previews, notifications, and list items with thumbnails.

Class summary

Class Purpose
d-flex Creates the media object row.
flex-column flex-md-row Stacks on mobile and places image left/content right from medium screens.
align-items-start Aligns the image and content at the top.
gap-4 Adds spacing between the image and content.
