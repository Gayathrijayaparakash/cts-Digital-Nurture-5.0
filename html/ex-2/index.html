Exercise 2.1 — Bootstrap directory parts

CSS folder
Compiled styles: layout rules, components (cards/nav/buttons), utilities, variables. In your download, that’s provided by bootstrap.min.css.
JS folder
Bootstrap’s interactive plugins (modal, dropdown, tooltip/popover, collapse, carousel, etc.). Your page loads them from bootstrap.bundle.min.js (includes Popper).
Icons folder
Icon assets used by Bootstrap ecosystem (commonly the Bootstrap Icons SVG set, or icon font assets). If your distribution doesn’t include it, Bootstrap will still work—icons are optional.
Note: Your current local download contains CSS + JS files; icons may not be present as a separate folder in this simplified sample.
