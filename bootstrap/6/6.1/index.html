Class summary

Class Purpose
d-flex Turns the navbar into a flex container.
flex-column Stacks navbar items vertically on small screens.
flex-md-row Changes navbar items to a horizontal row from the medium breakpoint.
align-items-md-center Vertically aligns items in the horizontal navbar layout.
