Exercise 16.1

Fixed Footer

This page uses Bootstrap position utilities to keep the footer fixed to the bottom of the viewport.

position-fixed bottom-0 start-0 end-0

Always Visible

The footer stays attached to the bottom of the browser window even while the page content scrolls.

Content Padding

The body has bottom padding so the fixed footer does not cover the last section.

Step One

Add position-fixed to remove the footer from normal document flow.

Step Two

Add bottom-0 to anchor the footer to the bottom edge.

Step Three

Add start-0 end-0 so it stretches across the viewport.
