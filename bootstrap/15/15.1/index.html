Border Utility Image

This image uses Bootstrap border utilities to add a thick primary circular border.

class="img-fluid border border-primary border-3 rounded-circle"

border

Turns on the border.

border-primary

Sets the color.

border-3

Increases width.

rounded-circle

Default Border

A plain border gives the element a standard outline.

Primary Border

border-primary applies the theme's primary color.

Thick Circle

border-3 and rounded-circle create the final image style.
