How the layout works

Screen size Class behavior Result
Extra small col-12 Each column takes the full row and stacks vertically.
Small and larger col-sm-3 Each column takes 25% of the row, creating four equal columns.
Total width 3 + 3 + 3 + 3 = 12 The four columns exactly fill Bootstrap's 12-column grid.
