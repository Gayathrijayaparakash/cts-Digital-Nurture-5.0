Explore the Bootstrap Directory Structure

This page explains the purpose of the CSS, JS, and icons folders found in a Bootstrap download.

Note: This simplified local download contains compiled CSS and JS files. A separate icons folder is not required for Bootstrap components to work.

CSS

CSS Folder

Controls the visual design of Bootstrap pages.

The CSS folder contains compiled stylesheet files such as bootstrap.css and bootstrap.min.css.

These files provide Bootstrap's grid system, spacing utilities, colors, typography, buttons, cards, forms, navbars, alerts, and responsive layout rules.

JS

JS Folder

Adds behavior to interactive components.

The JS folder contains JavaScript files such as bootstrap.js, bootstrap.min.js, and bootstrap.bundle.min.js.

These files power components like modals, dropdowns, collapses, carousels, toasts, tooltips, popovers, tabs, and offcanvas menus. The bundle file includes Popper, which is needed for tooltips and popovers.

ICO

Icons Folder

Stores optional icon assets.

Bootstrap Icons may be downloaded separately and stored in an icons folder as SVG files or icon font assets.

Icons are used to improve buttons, navigation, status messages, dashboards, and forms. They are optional: Bootstrap's layout and components still work without them.

Summary
