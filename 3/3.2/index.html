Class summary

Class Purpose Used here for
.container Centers content and adds responsive horizontal padding. Header and main page wrapper.
.row Creates a flex grid row and manages gutters between columns. Hero info, content/sidebar, and feature sections.
.col-* Controls column width across Bootstrap breakpoints. col-12, col-md-6, col-lg-8, col-lg-4, col-xl-3.
